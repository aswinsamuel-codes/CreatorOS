# Your own content

Drop `.md` or `.txt` files here: ideas, experiences, rough drafts, project write-ups,
lab experiments, opinions. Anything you want turned into a blog post.

The `personal` slot in `config.yaml` (21:00 by default) picks the next unused note and
turns it into a polished post in your voice. Each note is used once.

Example: `my-lab-cluster.md`

```
I built a cluster of old PCs in my lab to run Gemma and Llama models locally.
Problems I hit: ... What I learned: ... Cost compared to cloud: ...
```
