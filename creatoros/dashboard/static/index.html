Point the agent at a folder of certificates, badges, project screenshots or event photos (JPG, PNG, WEBP, PDF). It reads every file, writes the post(s) and sends them for your approval.

🎬 Video → post

Give a video file or a folder of videos (MP4, MOV, WEBM, MKV). The agent watches sample frames (and the transcript if available), then writes the YouTube title, description, tags, chapters and a LinkedIn caption. Vertical videos up to 3 minutes go out as YouTube Shorts.
